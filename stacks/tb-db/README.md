# ThingsBoard Database (TimescaleDB / PostgreSQL)

Prerequisite database layer for ThingsBoard Core Application.

## Installation Order: 1st
You must install and start this database **first** before deploying `tb-app` or `tb-edge`.

## Ports
- **5432**: TimescaleDB / PostgreSQL port.

## Credentials
- **User**: `postgres`
- **Database**: `thingsboard`
- **Password**: `qwer1234`
